# Carbculator 개발일지

> 인슐린을 사용하는 당뇨인을 위한 **간단 참고용 탄수화물·인슐린 계산기** 개발 기록.
> 커밋 이력(2026-08-03 ~ 2026-08-06)을 기반으로 각 변경의 배경·의도·해결 과정을 정리했습니다.
> ⚠️ 본 앱의 계산은 참고용이며 의료기기가 아닙니다.

---

## 📌 프로젝트 개요

- **플랫폼**: iOS (SwiftUI, iOS 17+), 한국어/English
- **핵심**: 식사 전 혈당·식사량을 입력하면 개인 계수(ICR·ISF) 기반으로 참고 인슐린을 계산
- **설계 원칙**: 단순함 우선 — 복잡한 임상 변수는 의도적으로 배제, "즉석 참고"에 집중
- **저장소**: https://github.com/devchoi84/carbculator (private)

## 🗓 Day 1 — 2026-08-03 : 초기 구현 & 기반 다지기

### v1 코어 구현 `f08a128`
- **인슐린 볼러스 계산기 v1** 완성: 온보딩 마법사 + 매 식사 계산 플로우 + 한/영 전환
- 계산식 확립:
  - 식사 인슐린 = 탄수화물 ÷ ICR
  - 교정 인슐린 = (현재 혈당 − 목표) ÷ ISF
  - 권장 = max(0, 식사+교정) → **펜 단위 내림**(저혈당 보수적 처리)
- 온보딩: ICR/ISF를 몰라도 시작하도록 4가지 추정(평소 식사 역산·직접 입력·병원 처방·500/1800 법칙)
- 구조: `InsulinCalculator`(순수 계산 엔진)와 UI 분리, `@AppStorage` 기반 로컬 저장
