# Carbculator 개요 문서

> 이 문서는 Carbculator 앱의 개요, 화면 흐름, 계산 원리, 안전장치, 기술 구조를 정리한 개발/설명용 문서입니다.
> ⚠️ 본 앱의 계산 결과는 **참고용**이며 의료기기가 아닙니다. 실제 인슐린 투여는 반드시 담당 의료진의 처방과 지침을 따릅니다.

---

## 1. 개요

**Carbculator**(Carb + calculator = 탄수화물 계산기)는 1형 당뇨인이 식사 전에 **"이 정도 식사를 할 건데 인슐린을 얼마나 맞아야 할까"** 를 빠르게 가늠하도록 돕는 **간단 참고용 인슐린 볼러스 계산기**입니다.

- **컨셉**: 정밀 임상 도구가 아니라 **즉석에서 가볍게 참고**하는 어시스턴트
- **대상**: 인슐린을 사용하는 당뇨인 (특히 한국 음식 위주 식사)
- **플랫폼**: iOS (SwiftUI), 한국어 / English 지원
- **설계 원칙**: 단순함 우선 — 입력 부담을 늘리는 복잡한 변수(실시간 IOB 차감, 끼니별 프로필 등)는 의도적으로 배제
- **데이터**: 설정·내역은 기기 로컬에만 저장. 음식 검색 시에만 검색어가 식약처 공공 API로 전송

## 2. 핵심 용어

| 용어 | 의미 |
|---|---|
| **ICR** (탄수화물 계수) | 인슐린 1단위(U)가 처리하는 탄수화물 양(g/U) |
| **ISF** (인슐린 민감도 지수) | 인슐린 1단위가 낮추는 혈당(mg/dL) |
| **목표 혈당** | 식전에 유지하고 싶은 기준 혈당(mg/dL) |
| **펜 단위** | 인슐린 펜의 최소 조절 단위 (1 U 또는 0.5 U) |
| **볼러스** | 식사/교정을 위해 추가로 주사하는 인슐린 |

---

## 3. 계산 원리

```
식사 인슐린  =  탄수화물(g)  ÷  ICR
교정 인슐린  =  (현재 혈당 − 목표 혈당)  ÷  ISF
권장 인슐린  =  max(0, 식사 인슐린 + 교정 인슐린)  →  펜 단위로 내림
```

- 현재 혈당이 목표보다 **낮으면** 교정 인슐린이 음수가 되어 식사 인슐린에서 **차감**됩니다.
- 합계가 음수면 **0**으로 처리해 과다 투여를 방지합니다.
- 최종값은 반올림이 아니라 **펜 최소 단위로 내림**하여 저혈당 위험을 낮춥니다.
- 교정(ISF)을 끄면 **식사 인슐린만** 계산합니다.

### 온보딩에서 쓰는 역산·추정식

| 값 | 방식 | 계산식 |
|---|---|---|
| ICR | 평소 식사 역산 | `음식 탄수화물 ÷ 그 식사 인슐린` |
| ICR | 병원 처방 기준 | `처방 탄수화물 ÷ 처방 인슐린` |
| ICR | 하루 총 인슐린(TDD) | **500의 법칙** → `500 ÷ TDD` |
| ISF | 하루 총 인슐린(TDD) | **1800의 법칙** → `1800 ÷ TDD` |
| ISF | ICR 기반 추정 | `ICR × 3.6` |

## 4. 화면 흐름

```
앱 실행
  │
  ▼
[ 스플래시 ]  흰 배경 + 로고 (약 1.5초)
  │
  ▼
[ 참고용 안내 팝업 ]  '확인'(이번만) / '다시 보지 않기'(영구)
  │
  ├─ 온보딩 미완료 ─▶ [ 온보딩 마법사 (7단계) ]
  │                     ① ICR 방식 → ② ICR 입력/계산
  │                     ③ ISF 방식 → ④ ISF 입력/추정 (건너뛰기 가능)
  │                     ⑤ 목표 혈당 → ⑥ 펜 단위 → ⑦ 요약·완료
  │                             │
  ▼                             ▼
[ 메인 계산기 (매 식사) ]  ◀────┘
   ① 현재 혈당 입력
        ▼
   ② 식사 입력 (음식 검색 + 섭취량 g  또는  탄수화물 직접 입력)
        ▼
   ③ 결과: 권장 인슐린 + 상세 내역
        · 첫 결과 시 '참고용' 안내 팝업 1회
        · 저혈당(≤70)이면 자동 감량 + 주의 안내
        · 권장량 20U 초과 등 이상치면 입력 재확인 경고
        · 하단: [새로 계산하기] · [산출내역 보기]

⚙️ 설정: 언어 · ICR 수정 · ISF/교정 · 목표혈당 · 펜 단위 · 문의 · 초기설정 다시하기
🕗 산출내역: 최근 7일 식사·인슐린 목록 (이후 자동 삭제)
```

## 5. 주요 기능

- **스마트 온보딩** — ICR/ISF를 몰라도 4가지 방식으로 자동 계산·추정
- **음식 검색 (식약처 DB)** — 음식명을 검색해 여러 음식을 담고, 각 음식의 **섭취량(g)** 을 조절하면 탄수화물이 자동 합산 (기본 100g, 이름 기준 중복 제거·관련도 정렬)
- **탄수화물 직접 입력** — 검색 없이 총 탄수화물만 입력하는 모드
- **저혈당 대응** — 혈당이 낮아도 계산을 막지 않고 자동 감량 + 주의 안내
- **이상치 경고** — 권장량이 비정상적으로 크면(기본 20U 초과) 입력 재확인 안내
- **계산 내역(7일)** — 완료된 식사·인슐린을 최근 7일 보관, 결과 화면에서 목록 확인
- **다국어** — 앱 내 한국어 / English 즉시 전환
- **문의** — 설정 내 이메일(maroon.choi@gmail.com) 링크

## 6. 안전장치 요약

| 계층 | 내용 |
|---|---|
| 실행 시 | 참고용 안내 팝업 (다시 보지 않기 지원) |
| 첫 결과 시 | 참고용 안내 팝업 1회 |
| 결과 화면 상시 | "의료진 지침 우선" 안내, IOB(잔여 인슐린) 주의 |
| 계산 로직 | 저혈당 자동 감량, 펜 단위 내림, 음수 방지(0 처리) |
| 이상치 | 권장량 과다 시 입력 재확인 경고 |
| 입력 검증 | 혈당 20~600, 목표 혈당 80~180 범위 안내 |

> 참고: 실시간 IOB 차감, 끼니별 ICR/ISF, 데이터 백업/내보내기는 **간단함 유지**를 위해 의도적으로 포함하지 않았습니다.

## 7. 데이터 & 개인정보

- 설정값·계산 내역은 `@AppStorage`(UserDefaults)로 **기기 로컬**에만 저장 (계정·자체 서버 없음)
- 계산 내역은 최근 **7일**만 보관 후 자동 삭제
- **음식 검색 시에만** 검색어가 식약처(공공데이터포털) 식품영양성분 API로 전송(HTTPS). 혈당·인슐린 등 개인 수치는 전송하지 않음
- 서비스키는 `FoodAPIConfig.swift`에 두고 `.gitignore` 처리 (원격 미포함)

## 8. 기술 구조

- **아키텍처**: 순수 SwiftUI + async/await (Combine 미사용), 상태는 `@State`·영속 설정은 `@AppStorage`
- **계산 분리**: `InsulinCalculator`는 UI에 의존하지 않는 순수 함수로 테스트·재사용 용이

## 9. 범위와 한계

- **의료기기가 아닌 참고용 도구**입니다. 인슐린 용량을 계산·제시하므로, 정식 앱스토어 공개나 배포 시에는 각국 규제(예: 한국 식약처의 의료기기/웰니스 구분, Apple App Store 가이드라인 1.4.1 등)를 별도로 확인해야 합니다.
- 실시간 잔여 인슐린(IOB), 운동·질병·시간대 변수는 계산에 반영되지 않습니다.
- 음식 탄수화물은 식약처 DB의 100g 기준 근사치이며, 실제 섭취량·조리법에 따라 달라질 수 있습니다.
